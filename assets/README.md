# 静态资源目录

本目录存放项目的静态资源文件，不参与代码运行。

## 目录结构

```
assets/
├── logos/           # 项目 Logo 和架构图
├── social/          # 社交媒体图片（群二维码、支付二维码）
└── demo/            # 效果展示图（用于 README）
```

## 说明

- `logos/` - 包含项目 Logo 和架构图
- `social/` - 包含微信群、QQ 群二维码和支付二维码
- `demo/` - 包含 OCR 识别效果展示图

## 测试图片

测试图片位于 `onnxocr/test_images/` 目录，用于代码测试和功能验证。

## 样例数据

垂直行业 CLI 的样例数据位于 `data/samples/` 目录。
